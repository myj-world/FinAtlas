REST API reference

          
Protected endpoints accept a Supabase access token via Authorization: Bearer <token>.


          

            
POST /api/screen/single

            
Screen one transaction and persist the result.

            
curl -X POST "https://your-host/api/screen/single" \\
  -H "Authorization: Bearer <token>" \\
  -H "Content-Type: application/json" \\
  -d '{"transactionId":"TX-1","transactionDate":"2026-10-19","transactionType":"wire","amount":1500,"currency":"USD","senderName":"Alice","senderCountry":"US","receiverName":"Bob","receiverCountry":"GB"}'

          


          

            
POST /api/screen/batch

            
Screen a JSON list immediately, or upload a CSV. Add ?async=true to queue background processing.

            
curl -X POST "https://your-host/api/screen/batch?async=true" \\
  -H "Authorization: Bearer <token>" \\
  -F "file=@transactions.csv"

          


          

            
GET /api/screen/batch/<batch_id>

            
Poll the status and results of a background batch job.

          


          

            
GET /api/screenings

            
List persisted screenings for the signed-in investigator.

          


          

            
GET /api/screenings/stats

            
Dashboard statistics: risk distribution, disagreements and open cases.

          


          

            
POST /api/cases

            
Create an investigation case linked to a screening.

            
curl -X POST "https://your-host/api/cases" \\
  -H "Authorization: Bearer <token>" \\
  -H "Content-Type: application/json" \\
  -d '{"screening_id":"<id>","status":"open","notes":"Escalated for review"}'
