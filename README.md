# FinAtlas

**AI-powered money laundering detection for banks and businesses.**

FinAtlas is an AI-powered AML platform that combines rule-based transaction monitoring with independent AI analysis to identify potential financial risks, challenge false-positive alerts, and uncover suspicious patterns that traditional rules may miss.

## Features

- CSV transaction import and analysis
- Rule-based risk scoring
- AI-powered detection of missed risks and potential false positives
- Investigation reports with evidence and explanations
- Risk dashboard and case management
- Secure authentication and persistent investigation records

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Data Processing:** Pandas
- **Database & Authentication:** Supabase
- **AI:** Hosted model API

The final stack and feature scope may evolve during the hackathon.

## Getting Started

1. Clone this repository.
2. Install the project dependencies.
3. Configure the required environment variables for Supabase and the AI provider.
4. Start the Flask application and open it in your browser.

Detailed setup instructions will be updated as the implementation is finalised.
