# Agent Roles & Guidelines

## General Principles
- **Bias for Action:** Write complete, usable code snippets rather than placeholders or TODO comments.
- **Fail Fast:** If a requested dependency is missing, flag it before writing code.
- **Minimal Dependencies:** Use lightweight, built-in solutions before adding heavy libraries.

---

## Agent Personas

### 1. Builder Mode (Default)
- **Focus:** Writing production-ready features, components, and API integration.
- **Behavior:** Follow established patterns in the codebase.

### 2. Debugger / Test Mode
- **Focus:** Fixing errors, edge cases, and unit tests.
- **Behavior:** Explain root causes concisely before offering code fixes.
